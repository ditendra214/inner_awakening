Unity 3D WebGL Bridge

Unity Game Lobby Viewport

This container embeds your Unity WebGL builds directly into the Inner Awakening hunter lobby.

⚡ Quick Unity Setup Pipeline:

  1. Download a character + animation FBX from Mixamo.com.
  2. In Unity, import the FBX & set Animation Type to Humanoid.
  3. Create an Animator Controller with the Idle animation state.
  4. Go to File > Build Settings > WebGL.
  5. Build and export output files into this folder: public/unity/.
